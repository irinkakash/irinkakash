# opencode.md — Личный дамп

## Кто я

Учитель английского языка. Работаю с документами, отчётами, презентациями и учебными материалами ежедневно.

---

## Повседневные задачи

### 1. Подготовка планов уроков / презентаций
- Составление конспектов уроков по ФГОС
- Создание презентаций (PowerPoint, Google Slides)
- Подбор лексики и грамматических упражнений
- Подготовка материалов для ВПР по английскому языку
- Работа с учебниками Spotlight (2–11 класс)

### 2. Обработка сообщений
- Письма родителям и обучающимся
- Телефонограммы
- Электронная переписка с коллегами и руководством

### 3. Анализ документов
- Проверка и систематизация сертификатов
- Обработка сканов документов (PDF → Markdown/текст)
- Работа с нормативными документами (ФГОС, положения)

### 4. Подготовка отчётов
- Отчёты по результатам обучения
- Дневники периодов (напр. Чечель В. А.)
- Списки обучающихся по программам
- Стенгазеты и информационные стенды

### 5. Проверка и оценивание аудиофайлов
- Прослушивание аудиозаписей устных ответов обучающихся
- Оценивание произношения, беглости, лексического разнообразия
- Обратная связь по аудио-домашним заданиям
- Работа с аудио-приложениями к учебникам

---

## Структура рабочей папки

```
Default Project/
├── my docs/           — личные и рабочие документы (PDF)
├── reports/           — готовые отчёты и аудиты (HTML)
└── opencode.md        — этот файл
```

---

## Частые форматы

| Тип | Формат | Пример |
|-----|--------|--------|
| Урок/план | .md, .docx | конспект урока |
| Презентация | .pptx | презентация к уроку |
| Сертификат | .pdf | сертификат участника |
| Отчёт | .html, .md | дашборд, итоговый отчёт |
| Список | .xlsx | списки обучающихся |
| Аудио | .mp3, .m4a | устные ответы, аудио-приложения |

---

## Инструменты

- **opencode** — анализ файлов, генерация отчётов, конвертация форматов
- **VS Code** — редактирование Markdown и кода
- **PowerShell** — скрипты автоматизации (анализ папок, пакетная обработка)

### Команды opencode

| Команда | Что делает |
|---------|-----------|
| `/plan тема, класс` | Генератор конспекта урока по ФГОС |

---

## Заметки

- Все файлы переименовывать по формуле: `[дата — опционально] — [тема] — [тип].md`
- `opencode.md` всегда в корне рабочей директории
- PDF конвертировать в Markdown при необходимости
